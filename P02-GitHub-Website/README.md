# P02 太阳能泳池投射灯研究工作台

完整静态网站，包含竞品、月度数据、美国50州互动地图、评论研究、产品定义、质量验证、开发计划、关键词和十款中文创新设计。图片、数据均随仓库提供，无需安装依赖、构建或填写API密钥。

## 上传与发布

1. 新建 GitHub 仓库。
2. 把本文件夹**内部所有文件与 assets 文件夹**上传到仓库根目录，让 index.html 直接位于根目录。不要只上传 index.html，也不要多套一层文件夹。
3. 在仓库的 Settings → Pages，选择 Deploy from a branch。
4. Branch 选择 main（或实际上传的分支），目录选择 / (root)，保存。
5. 等待发布完成，使用 Pages 页面显示的网址访问。项目仓库通常为 https://你的用户名.github.io/仓库名/ 。

如果网页显示404，先检查分支、根目录的 index.html 及发布状态。文件名区分大小写，assets 路径不要改名。

## 本地预览

不要直接双击 index.html：浏览器可能禁止它读取 data.json。电脑已安装 Python 时，在本文件夹打开终端，运行：

```sh
python -m http.server 8000
```

然后打开 http://localhost:8000/ 。GitHub Pages 上不需要这个步骤。

## 文件说明

- index.html：网站入口。
- style.css：页面样式。
- app.js、content.js：研究页面、文字与交互。
- climate.js：地域月份地图、温度数据与销量情景交互。
- concepts-v3.js：十款中文设计方案展示。
- data.json：全部网站结构化数据。
- assets/：原始截图、设计图、评论来源文档；仅保留2026-10-13全新素白海钻概念图；旧概念图已移除。
- .nojekyll：让 GitHub Pages 直接发布静态文件。
- FILE-MANIFEST.json：文件大小与SHA-256校验清单。

## 数据与设计说明

研究数据快照日期为2026-10-09；全新白色设计日期为2026-10-13。本网站没有自动同步后台或实时更新功能。州级销量为明确标注的模型情景，不是真实州订单；概念图不是工程图或实测投射效果。页面中的CSV、任务书和图片下载均在浏览器本地生成或读取仓库文件。
